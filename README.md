# TgUnlocker

**Локальный MTProto-прокси для Telegram на Android. Работает через WebSocket, без сторонних серверов и без VPN.**

## Что это

TgUnlocker поднимает на телефоне маленький прокси-сервер (`127.0.0.1:1080`). Telegram подключается к нему как к обычному MTProto-прокси, а приложение заворачивает трафик в TLS WebSocket и отправляет его к дата-центрам Telegram. Если прямой путь заблокирован, трафик идёт через запасные Cloudflare-зеркала.

- Не нужен VPN и свой сервер.
- Трафик не уходит на чужие прокси: всё работает локально на устройстве.
- Один тап для настройки Telegram (ссылка `tg://proxy`).
- Автозапуск после перезагрузки, работа в фоне через foreground-сервис.
- Живые логи прямо в приложении.

## Как это работает

```
Telegram  ──MTProto──▶  127.0.0.1:1080 (TgUnlocker)  ──TLS + WebSocket──▶  DC Telegram
                                                      └─ запасной путь: Cloudflare-зеркала
```

1. Telegram шлёт MTProto-хендшейк на локальный порт.
2. TgUnlocker читает номер дата-центра из обфусцированного заголовка.
3. Открывает WebSocket-соединение к нужному DC (напрямую или через зеркало).
4. Перешифровывает поток и гоняет данные в обе стороны.

## Установка

1. Скачайте последний `.apk` на вкладке [**Releases**](../../releases).
2. Разрешите установку из неизвестных источников.
3. Установите и откройте приложение.

Требуется Android 7.0 (API 24) или новее.

## Использование

1. Нажмите **Start Tunnel** (на Android 13+ разрешите уведомления).
2. Нажмите **Set up in Telegram** — Telegram предложит добавить прокси, подтвердите.
3. Готово. Для стабильной работы нажмите **Allow** в блоке *Battery optimization*, чтобы система не убивала сервис.

### Настройки

| Параметр | Что делает |
|---|---|
| **Start on boot** | Запускает прокси после перезагрузки телефона |
| **Battery optimization** | Просит исключить приложение из энергосбережения |
| **Custom CDN / Relay domain** | Необязательно. Если у вас есть свой домен (например, на Cloudflare), впишите его, и приложение будет работать через него, а не через встроенные зеркала. Обычно не требуется |
| **Local Port** | Локальный порт прокси, по умолчанию `1080`. Можно поменять на любой свободный |

## Сборка из исходников

Нужны Android Studio и JDK 17+.

```bash
git clone https://github.com/Qual1ty-dev/TgUnlocker.git
cd TgUnlocker
./gradlew assembleDebug
```

APK окажется в `app/build/outputs/apk/debug/`.

## Частые вопросы

**Telegram не подключается.** Проверьте, что туннель запущен и порт в приложении совпадает с портом в настройках прокси Telegram. Посмотрите логи (строки `[WS_FAIL]`, `[ERR]`).

**Сервис сам останавливается.** Выдайте исключение из оптимизации батареи и закрепите приложение в списке недавних (на некоторых прошивках: Xiaomi, Huawei, Samsung).

## Безопасность

- Прокси слушает только `127.0.0.1`, из локальной сети он недоступен.
- Содержимое сообщений остаётся зашифрованным end-to-end самим Telegram, прокси видит только зашифрованный MTProto-поток.
- Приложение не собирает и не отправляет никакие данные об устройстве.
